## Implementation summary

- Added the frozen `teamSeats` contract by publishing the existing same-team membership query as a UID-keyed, scope-safe read-only map. Opponent seats are never subscribed, and absent-role `actsAs` behavior remains unchanged.
- Added one student-route `RoundPresentationProvider` that owns the current-round listener, a five-entry game/user-scoped historical cache, safe historical reads, stale-listener guards, and session-local elapsed reveal progress.
- Kept simulation scores server-authored: SIMULATE rows are derived only from the server round document and the revealed game prefix through `liveStandings`; RESULTS and FINALE expose the completed round. Current-SIMULATE and future historical reads are refused.
- Preserved presentation progress across student route changes and session remounts, with the frozen 1200 ms intro and clamped elapsed interval. Reveal next, Reveal all, and reduced-motion completion are local-only and perform no server writes.
- Converted `useRoundDoc` into the compatible shared-cache facade and kept professor/projector routes outside the student presentation provider, so those routes do not start student listeners.
- Added the persistent franchise header with identity, actual role, safe presentation record, phase/round title, paused/live timer, and Standings navigation. Loading uses an em dash and never falls back to final `TeamDoc` wins. Payroll sticky positioning shares `--ss-student-header-offset`.
- Guarded `/standings` during SIMULATE with presentation rows and raw permitted arithmetic, while preserving the existing historical Standings screen outside SIMULATE and keeping the route stable through RESULTS.
