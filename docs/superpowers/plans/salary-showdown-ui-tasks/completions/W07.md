Historical page state is keyed by game, auth UID, and round so a replacement user cannot see the prior user's local table while its own read is pending.

- Added stable team-ID row keys and a 600ms maximum FLIP-style reorder animation that respects the shared reduced-motion hook and is disabled while the round selector has focus.
