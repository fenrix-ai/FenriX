## Implementation

- Added exact-shape `TeamIdentity` validation for the frozen accent and jersey enums.
- Added authenticated, lobby-only `setTeamIdentity({ gameId, identity }) -> { ok: true }`.
- The callable validates the game document ID before constructing Firestore references, ignores caller-supplied `teamId`, derives the target exclusively from membership, and reads the game, membership, and team in one transaction before updating only `identity`.
- The transaction reads the same game document updated by `startSeason`, so a concurrent save either commits before the transition or retries and rejects after the lobby closes.
- `getLobby` keeps its existing public fields and adds `identity` only when stored metadata passes the same validator. Old or malformed stored metadata is omitted.
- Existing team defaults remain unchanged; old games require no migration.
